# AuraAI — Modern AI SaaS Landing Page Template

A clean, customizable landing page template for AI SaaS and micro-SaaS products.

## Included

- Responsive English landing page
- Light visual system with white, gray, lime, and violet
- Hero, product preview, features, pricing, and footer sections
- Subscription cards with Join CTAs
- Semantic HTML structure
- Tailwind CSS via CDN for quick customization
- No backend lock-in: ready to connect to any REST API, Supabase, Firebase, PostgreSQL, MySQL, or custom backend

## Quick start

1. Open `index.html` directly in a browser, or run a local server:

   ```bash
   python3 -m http.server 4173
   ```

2. Open `http://localhost:4173`.

## Customization

- Replace `AuraAI` and the page copy in `index.html`.
- Update colors using the Tailwind utility classes.
- Replace the product preview code block with your own product UI.
- Connect the waitlist and Join buttons to your own API or form provider.
- Add environment variables and a backend integration without changing the visual sections.

## Notes

This is a frontend template. Forms and subscription buttons are intentionally ready for backend/API integration and do not process payments by themselves.
